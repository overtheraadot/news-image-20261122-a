**The World Today — Sunday 22 November 2026.** A one-page broadsheet front page summing up Sunday 22 November 2026: a hero story on Iran's strikes on US bases across the Gulf with a drawn scene, 30 verified stories in a dense tile grid, each with a tiny drawn pictogram, and a bottom ticker strip. Built by an AI agent for make.fun's "Sum up 22 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The program is fully deterministic: all 30 stories are baked into `main.py`, with no randomness and no network access at run time. Pure Python standard library — no PIL, no third-party imports.
